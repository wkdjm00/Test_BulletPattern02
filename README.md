# Test_BulletPattern02

C# / Unity 학습을 위한 연습용 프로젝트입니다. Unity URP 템플릿을 기반으로 시작했고, 배운 C# 문법을 하나씩 실제 게임 기능으로 옮기면서 점차 완성해 나갑니다.

## 프로젝트 목표

이 저장소는 완성된 게임이 아니라, C# 문법을 배우면서 그 개념을 실제 코드로 직접 옮겨보는 학습용 프로젝트입니다. 하루하루 배운 내용을 코드로 구현하고, 그 과정을 커밋으로 남깁니다.

## 진행 상황

- 현재는 Unity URP 빈 템플릿 상태입니다. 아직 커스텀 스크립트는 없습니다.
- 앞으로 플레이어 이동 -> 공격 -> 적 -> 아이템 -> 점수/UI 순서로 기능을 하나씩 추가할 예정입니다.

## 개발 환경

- Unity (URP)
- C#
- Input System 패키지
